# scribe-marceau
L’École Nouvelle d’Égyptologie (ENE) se distingue par une approche résolument innovante de l’étude des hiéroglyphes, fondée sur trois principes :  Réhabilitation des systèmes phonogrammiques originels (dont l’aibôcôdère (akan/agnî) est le principe.  Intégration des données linguistiques africaines dans l’analyse des textes égyptiens.
